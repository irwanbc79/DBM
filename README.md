# Dira Baraka Mulia Website

Website untuk PT Dira Baraka Mulia yang di-deploy otomatis ke Hostinger via GitHub Actions.

## Struktur Project
- `dira-improved/` - Website files yang di-deploy ke public_html
- `.github/workflows/deploy.yml` - Workflow untuk auto-deploy

## Deployment
Setiap push ke branch `main` akan otomatis deploy ke https://dira.co.id
